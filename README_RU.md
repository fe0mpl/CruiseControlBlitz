**Круиз-контроль для World of Tanks Blitz и Tanks Blitz** – программа, которая позволяет назначить отдельные клавиши для движения вперёд и назад, чтобы танк ехал без необходимости постоянно удерживать кнопки.

## 🔥 Возможности

- 🎮 **Назначьте любые клавиши** – поддерживаются комбинации с `Ctrl`, `Alt`, `Shift`, `Win`.
- 💾 **Настройки сохраняются** в папке `Документы\CruiseControl\cruise_settings.ini`.
- 🚫 **W и S не перехватываются** – они работают как обычно в игре.
- ⚡ **Не требует установки** – один `.exe` файл.
- 🔄 **Экстренная остановка** – по нажатию кнопки «Стоп».

## 🛠 Использование

1. **Запустите** `CruiseControl.exe` (желательно **от имени администратора**).
2. **Настройте клавиши**:
   - Нажмите на кнопку «Вперёд» → нажмите нужную клавишу (например, `W` или `Ctrl+W`).
   - Повторите для «Назад» и «Стоп».
   - Если передумали – нажмите `Esc` для отмены.
3. **Включите круиз**:
   - Нажмите зелёную кнопку «Включить» – она станет красной с надписью «Выключить».
4. **В игре**:
   - Нажмите назначенную клавишу для движения вперёд – танк поедет и будет ехать, пока вы снова не нажмёте ту же клавишу (остановка).
   - Аналогично для движения назад.
   - Для экстренной остановки нажмите клавишу «Стоп».
   - Клавиши `W` и `S` работают как обычно – они не влияют на круиз.

## 🔧 Сборка из исходников

Если вы хотите собрать программу самостоятельно:

### Требования
- Windows 7 / 8 / 10 / 11
- [AutoHotkey v1](https://www.autohotkey.com/)

### Инструкция
1. Установите AutoHotkey v1.
2. Сохраните `CruiseControl.ahk` в кодировке **UTF‑8 с BOM**.
3. Запустите `Ahk2Exe` (входит в AutoHotkey) и скомпилируйте `.ahk` в `.exe`.

---

## 🧰 Технологии

- **AutoHotkey v1** – язык для создания утилит под Windows.
- **Windows API** – для перехвата клавиш и работы с GUI.
